## any-format v0.0.2

首个功能完整版本：在 0.0.1 的文本 / 表格 / Office / PDF 基础上，新增**图片**与**音频**两条格式族，并把包名统一为 `any-format`。

```bash
npm i github:hefuhai001/any-format#v0.0.2
```

> **破坏性变更**：包名与导入名由 `anyformat` 改为 `any-format`。升级后请把 `import { convert } from 'anyformat'` 改成 `import { convert } from 'any-format'`。

### 新增能力一览

| 能力 | 格式 | 引擎 | 新增 API |
| --- | --- | --- | --- |
| 图片互转 | `png` `jpeg` `webp` `avif` `tiff` `gif` | `sharp`（可选） | `convertImage()`、`readImageInfo()` |
| 音频互转 | `wav` `mp3` `flac` `ogg` `aac` `m4a` | 外部 `ffmpeg` | `convertAudio()`、`resolveFfmpeg()`、`buildAudioArgs()` |

两族都是 6 × 5 = 30 条直达边，任意两种格式互转都不需要中转。

### 图片（`sharp`）

```ts
import { convertImage, readImageInfo } from 'any-format';

const webp = await convertImage(pngBuffer, 'webp', { quality: 75, lossless: false });
const { width, height, hasAlpha } = await readImageInfo(webp);
```

- 选项：`quality`（1–100，默认 82）、`lossless`、`background`（透明转 jpeg 时的底色，默认 `#ffffff`）、`animated`
- 透明图转 `jpeg` 自动压平；编码前按 EXIF 方向自动摆正
- 别名归一：`jpg` / `jpe` → `jpeg`，`tif` → `tiff`

### 音频（`ffmpeg`）

```ts
import { convertAudio } from 'any-format';

const mp3 = await convertAudio(wavBuffer, 'mp3', { bitrate: 192, sampleRate: 44100 });
```

- 选项：`bitrate`、`sampleRate`、`channels`、`compressionLevel`（flac 0–12）、`ffmpegPath`
- ffmpeg 解析顺序：`converterOptions.ffmpegPath` → `FFMPEG_PATH` → 可选包 `ffmpeg-static` → `PATH`
- 转码走 stdin/stdout 管道；`m4a` 用临时文件（mp4 复用器要求可 seek）并自动清理；WAV 输出补齐流式长度占位符
- `ogg` 固定 Vorbis，`bitrate` 自动换算为 `-q:a`

### 其他改进

- 格式探测补齐 8 种图片扩展名、8 种音频扩展名与 19 个 MIME 映射
- README 双语化：英文为默认（`README.md`），可切换到简体中文（`README.zh-CN.md`）
- PDF / PPTX 默认作者元数据改为 `any-format`
- 新增 `CHANGELOG.md`，本次及其后每个版本的说明归档在 `docs/releases/<tag>.md`

- **301** 项用例全部通过（0.0.1 为 273 项），图片/音频用例均为真实编码解码，不用 mock
- `tsc --noEmit`、`tsup` 构建、`publint` 校验均通过
- 发布包 10 个文件、152 kB（解压 640 kB），同时提供本次构建的 `.tgz` 附件
